## Quick Start

1. **Pick a language** — Python or TypeScript. Stay consistent.
2. **Get an API key** — [OpenAI](https://platform.openai.com/api-keys) or [Anthropic](https://console.anthropic.com/settings/keys)
3. **Start Module 1** — [Model Basics](foundations/01-model-basics.md)

No prior ML or LLM experience required. Comfortable with REST APIs and `async`/`await` is enough.

## Curriculum Overview

| Path | Modules | What you'll build |
|------|---------|-------------------|
| **Foundations** | 1–5 | API calls, prompt engineering, RAG pipeline |
| **Systems** | 6–10 | Tool-calling agent with memory, evaluation suite |
| **Extending** | 11–13 | Local models, multimodal processing, fine-tuned model |
| **Production** | 14–18 | Secured, streaming, observable, cached, deployed system |
| **[Capstone](capstone.md)** | All | Research Oracle — multi-turn agent with citations, critic, and constraints |
